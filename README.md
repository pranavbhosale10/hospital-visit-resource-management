# 🏥 Hospital Visit & Resource Management using SQL

A relational database project designed to simulate a real-world hospital management system using **MySQL and SQL**.

The system manages patient visits, doctor assignments, hospital rooms, services, billing and payments while maintaining data integrity and supporting automated workflows.

## 🛠️ Technologies

- MySQL
- SQL
- Relational Database Design
- JSON
- Entity Relationship Diagram (ERD)

## 📌 Key Features

- Hospital database and table creation
- Patient, doctor, department and appointment management
- Hospital room allocation
- Billing and payment management
- SQL joins and cross-table analysis
- Stored procedures for workflow automation
- JSON data handling
- Triggers for automatic updates
- Transactions and rollback
- SQL views for reporting
- Database normalization using **Third Normal Form (3NF)**

## 📊 Database Structure

The system contains **9 relational tables** covering:

**Patients • Appointments • Doctors • Departments • Hospital Rooms • Bills • Payments • Services • Service Usage**

The database follows **3NF normalization** to reduce redundancy, avoid update anomalies and maintain data consistency.

## 🔍 SQL Analysis

The project demonstrates practical SQL operations including:

- CRUD operations
- INNER JOIN and LEFT JOIN
- Aggregation and reporting
- Stored procedures
- Triggers
- Transactions
- JSON extraction
- Views
- Primary and foreign key relationships

## 🎯 Project Objectives

1. Manage hospital data efficiently
2. Connect information across departments
3. Automate hospital workflows
4. Handle flexible and semi-structured data using JSON
5. Ensure reliable and consistent database operations
